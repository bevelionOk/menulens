# Senior Full-Stack Engineer — Vibe-Coding / BMAD

**Remote · 20–40 h/week · Freelance or via remote.com · up to EUR 60k/year initial**

We are an **exciting industry-backed startup** working to digitalize, automate, and disrupt an entire vertical of an established industry. The founding operators already run a profitable business in this space. **The software is live and in use** — we're close to launch and need one more strong engineer to help finalize it, harden it, and bring it to market.

## What you'll do

- Own features end-to-end using **BMAD** — from brief through PRD, architecture, stories, implementation, and review
- Ship independently against a large TypeScript codebase with heavy AI/LLM automation
- Work async with a seasoned engineer who owns the product vision and reviews your PRs
- Communicate in writing: **build → explain what & why → get reviewed → ship → follow up**
- One weekly sync call — otherwise autonomous

## Stack

- **Frontend**: React + TypeScript, Vite, TanStack Query, Tailwind + shadcn/ui, Zod, Playwright
- **Backend**: Node.js + Fastify + TypeScript, PostgreSQL + Drizzle, Redis + BullMQ, JWT, S3-compatible storage
- **AI**: BMAD, OpenAI SDK (JSON mode + vision), n8n workflows, Claude Code
- **Infra**: Docker, GitHub Actions, Datadog (APM/logs/RUM)

## You'll thrive here if

- You love building and treat business outcomes as your KPI
- You take ownership of correctness in a system where mistakes have real financial consequences
- You've shipped real production features with BMAD (not just tutorials)
- You write crisply and think in trade-offs

## You will NOT thrive here if

- You need daily standups, detailed tickets, or someone pairing with you to make decisions

## How to apply

This is an **open competition**. Complete the coding challenge (see brief) and submit:

1. Working artifact + repo
2. Decision log
3. BMAD artifacts you used
4. **All prompts** you fed to any LLM during the build
5. **Personal video** (3–5 min): who you are, why this role
6. Walkthrough video (5–10 min): what you built, why, business risk
7. One-paragraph business note: what would you charge for this feature?
